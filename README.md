# 💈 BarberPro

Sistema completo de gestão para barbearias, desenvolvido com foco em praticidade, organização e escalabilidade. O BarberPro permite que barbeiros gerenciem seus atendimentos, clientes e serviços de forma simples e eficiente.

---

## 🚀 Sobre o projeto

O **BarberPro** é uma aplicação mobile desenvolvida para facilitar o dia a dia de barbeiros, permitindo o controle total da agenda, clientes e serviços em um único lugar.

Este projeto foi criado com foco em:

* Organização de atendimentos
* Experiência do usuário
* Estrutura escalável (pensando em SaaS no futuro)

---

## 📱 Funcionalidades

### 🗓️ Agenda Inteligente

* Criação e gerenciamento de horários
* Visualização dos atendimentos do dia
* Organização automática dos horários disponíveis

### 👥 Gestão de Clientes

* Cadastro de clientes
* Histórico de atendimentos
* Informações organizadas por cliente

### ✂️ Serviços

* Cadastro de serviços (corte, barba, etc.)
* Seleção de serviços no atendimento
* Controle de valores

### 💰 Consumo / Produtos

* Registro de produtos utilizados
* Controle de consumo por atendimento

### ⚙️ Configurações do Barbeiro

* Definição de horários de trabalho
* Personalização do funcionamento

---

## 🧠 Tecnologias utilizadas

* **Kotlin** (Android)
* **Android Studio**
* **Arquitetura baseada em Fragments**
* **RecyclerView (Listas dinâmicas)**
* **Material Design**
* **SupaBase / Banco de dados**
* **Node.js + PostGres (planejado para backend web)**

---

## 🏗️ Estrutura do Projeto

```
📁 adapter/        → Adapters das listas (RecyclerView)
📁 model/          → Modelos de dados
📁 repository/     → Camada de acesso a dados
📁 ui/             → Telas e Fragments
📁 util/           → Utilitários (ex: formatação)
```

---

## 🎯 Objetivo

O objetivo do BarberPro é evoluir para um sistema completo de gestão (SaaS), permitindo que barbeiros possam:

* Gerenciar sua barbearia de forma digital
* Automatizar processos
* Aumentar produtividade
* Ter controle financeiro e operacional
